# Monday-coffee-analysis

## Description
This project analyses coffee sales data using SQL to understand sales trends, customer behaviour, and market potential across different cities.

## Objectives
- Analyse total sales and revenue
- Identify top performing cities
- Calculate monthly sales growth
- Estimate potential coffee consumers by city
- Support business expansion decisions

## Tools Used
- MySQL
- MySQL Workbench
- GitHub

## Key Insights
- Pune, Chennai, and Bangalore are the top 3 cities by total sales
- Pune shows the highest estimated coffee consumer base
- Monthly sales growth highlights seasonal fluctuations
